# Retrospective Learning Backfill V1

Historical execution may be reconstructed from durable repository evidence when prospective Task Learning capture was not yet active.

Rules:
- reconstruction never upgrades evidence strength;
- every event must retain source references;
- `retrospective` and `prospective` ledgers remain separate;
- retrospective events are supporting evidence and do not automatically advance prospective review thresholds;
- repeated historical patterns may seed Framework Feedback only after review;
- no private reasoning, credentials, tenant/customer payloads, or large transcripts are copied into learning data.
